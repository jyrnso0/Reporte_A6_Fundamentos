Ejercicio 1: Modelo de caja y Flexbox

Actividad A6 – Fundamentos | Laboratorio de Programación Web

Instrucciones del ejercicio

Objetivo: comprender el modelo de caja y distribuir elementos con Flexbox.

  1. Crea un div y aplícale width, padding, border, margin y border-radius.
  2. Crea un contenedor con tres tarjetas (article), cada una con título y texto.
  3. Al contenedor aplícale display: flex, flex-wrap: wrap y gap.
  4. A las tarjetas aplícales flex: 1 1 200px para que se ajusten al ancho disponible.
  5. Agrega un efecto :hover a las tarjetas con transform.
  6. Agrega una regla @media (max-width: 600px) para pantallas pequeñas.

Entrega: archivos .html y .css y capturas del resultado en pantalla completa y con la ventana reducida.

El modelo de caja

Todo elemento HTML es una caja formada por cuatro capas: el contenido, el padding (espacio interior), el border (borde) y el margin (espacio exterior).

Esta caja tiene width, padding, border, margin y border-radius.

Tarjetas con Flexbox

Con display: flex las tarjetas se acomodan en una fila y, en pantallas pequeñas, pasan a otra línea.

HTML

Define la estructura y el contenido de la página.

CSS

Controla el aspecto: colores, espacios y distribución.

JavaScript

Agrega comportamiento e interactividad.
